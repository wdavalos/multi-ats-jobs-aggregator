# ATS Job Scraper API - Greenhouse, Lever, Ashby, SmartRecruiters

Scrape job postings from Greenhouse, Lever, Ashby and SmartRecruiters into one unified dataset: title, location, remote flag, department, apply URL, posted date and full plain-text description.
